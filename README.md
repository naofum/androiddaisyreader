# Android Daisy Reader

## デイジーリーダーとは

本を読むことが困難な人のためのデジタル録音図書の国際標準規格DAISY（デイジー）で作られた電子書籍を読む（聞く）アプリです。

## 主な機能と特徴

1. 3種類のデイジー図書に対応しています
    - **音声デイジー**：人間の声や合成音声による朗読と、見出しなどの構造化データ（主にDAISY 2.02規格）
    - **マルチメディアデイジー**：音声とテキスト（文字）、画像が同期しており、読まれている部分がハイライト表示される（EPUB 3、DAISY 2.02規格）
    - **テキストデイジー**：音声なしでテキストのみを構造化したもの（主にDAISY 3規格）

2. 無料で、広告も表示されません

3. オープンソースソフトウェアでソースコードを公開しています

## 使い方の紹介

ボタンの操作はダブルクリックです。クリック1回の場合はボタンの名前を読み上げます（メニュー操作や、設定はダブルクリックの必要はありません）

1. 本の開き方（いくつかの開き方があります）
    1. 無料で公開されているデイジー図書をダウンロードします「本のダウンロード」
        1. ダウンロードが完了はAndroidの通知で表示されます
        2. 通知をクリックすると本が開きます、シンプルモードとビジュアルモードを選んで本を開きます
    2. Androidのファイルで、対象のファイルを選んで「アプリで開く」を選びます
        1. デイジーリーダーを選びます
        2. 本が開きます、シンプルモードとビジュアルモードを選んで本を開きます
    3. 本を開くと、次からは最近読んだ本に表示されます
    4. このアプリでダウンロードした本は「本のスキャン」にも表示されます（Androidのバージョンによって表示される対象のファイルは変わります）

2. シンプルモード
        シンプルモードは音声で聞くことに特化しています。文章は表示されません。
        操作は画面のクリックと、スワイプで操作します
        画面中央をダブルクリック：目次を表示
        画面中央をクリック：再生の停止／再開
        下にスワイプ：次の章
        上にスワイプ：前の章
        右にスワイプ：次の節
        左にスワイプ：前の節

3. ビジュアルモード
    ビジュアルモードは、文章が表示されます。読んでいる箇所がハイライト表示されます。
    操作は、画面下部に表示されるボタンで操作します。
    メニューからいくつかの機能を使うことができます。（ブックマーク、目次、シンプルモードへの切り替え、など）
